# Reference

The entity layer. One note per thing you keep coming back to: a tool, a concept, an organisation,
a method.

A reference note answers: what is it, when to use it, when *not* to use it, what it costs, how it
fails. Detail belongs here — this is the layer where depth is correct.

## What does not belong here

- Raw sources → `00-capture/`
- Dated deliverables → `30-reports/`
- Step-by-step instructions with no explanation → those are method files; keep them short and
  link back here for the reasoning.
